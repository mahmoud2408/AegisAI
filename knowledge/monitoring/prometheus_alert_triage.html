Prometheus Alert Triage Note

This project-generated note supports retrieval tests for monitoring alerts. It is not official Prometheus documentation.

Alert evaluation

When an alert fires, check the alert expression, labels, annotations, firing duration, scrape health, missing series, and recent deployment changes.

Alert fatigue can occur when thresholds are too sensitive, labels are too broad, or alerts fire on symptoms without service impact.

Evidence

Capture alert name, severity, labels, query result, evaluation timestamp, dashboard panel, and related service-level indicators.
