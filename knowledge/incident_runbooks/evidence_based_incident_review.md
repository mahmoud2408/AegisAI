# Evidence-Based Incident Review Template

## Scope

This project-generated template supports AegisAI incident reports. It separates detected evidence, model inference, probable causes, and recommendations.

## Review sequence

Start with the incident timeline, severity, affected services, and evidence count. Review metric anomalies, forecast deviations, log evidence, state transitions, and historical context separately.

## Root cause language

Use cautious language. A root-cause candidate is not causal proof unless validated by topology, logs, telemetry, traces, and operator confirmation.

## Recommendations

Recommendations should cite observed evidence and include rollback, scaling, dependency checks, configuration review, or deeper investigation steps.
