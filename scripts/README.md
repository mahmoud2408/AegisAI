# Scripts

This directory will contain reproducible command-line entry points for dataset import, preprocessing, training, evaluation, benchmarking, and documentation ingestion.

Planned scripts:

- Dataset importers for NAB, SMD, and LogHub
- Synthetic telemetry generation
- Feature building
- Model training
- Model evaluation
- RAG document ingestion
- RAG retrieval evaluation
- Agent ablation benchmarks

Scripts should be deterministic where possible and must write run metadata.
